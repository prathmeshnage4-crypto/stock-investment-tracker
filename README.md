# Simple Stock Investment Tracker

## Project Description

This is a simple Python-based Stock Investment Tracker. It calculates the total investment value based on manually defined stock prices and user-entered quantities.

## Features

- Displays available stocks and prices
- Accepts stock name from the user
- Accepts stock quantity
- Calculates investment for each stock
- Calculates total investment value
- Saves the final result in a text file

## Technologies Used

- Python
- Dictionary
- Input/Output
- Basic Arithmetic
- File Handling
- Loops

## Stock Prices

The project uses manually defined stock prices:

- AAPL: $180
- TSLA: $250
- GOOGL: $150
- MSFT: $420
- AMZN: $190
